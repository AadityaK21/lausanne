#   - the local application
#   - both test suites
#
# Run with:  python -m pip install -r requirements-minimal.txt
#
# Add speaker labels later with:  python -m pip install pyannote.audio
# (and a Hugging Face token — see docs/SETUP_WINDOWS.md step 4)
